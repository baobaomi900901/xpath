# WEB Login Implementation Plan

**Goal:** 在已有 WEB 靶场中增加支持两种登录方式和模态错误提示的登录测试页。

**Architecture:** 新建 LoginTestPage，复用 PageLayout、Ant Design Tabs/Input/Modal/Result。表单负责本地校验和错误弹窗，页面负责登录成功状态与退出；沿用已有路由与首页入口模式。

**Tech Stack:** React 19、TypeScript、Ant Design 5、Vite 6、Node.js 与 Playwright 浏览器验收。

- 账号 `admin`，密码 `1`，手机号 `13922832244`，验证码 `1990`，均严格匹配。
