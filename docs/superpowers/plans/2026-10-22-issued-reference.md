# Shared Key Reference Implementation Plan

**Goal:** 按最新需求以内置共享密钥、金额及随机因子生成可验签流水号，同时完成 iframe 登记页。

**Architecture:** 共用无依赖 Web Crypto 模块实现 HMAC 与金额规范化；JSON 提供相同密钥配置。转账页异步生成并保存快照，iframe 登记异步验签，无额外 API 或存储。

- [x] 实现共用 HMAC 模块、类型声明与配置 v2，增加独立 Node 对照和随机/篡改测试。
- [x] 转账页异步生成，iframe 登记按金额验签，保留快照与重复提交禁用。
- [x] 更新两套浏览器测试与协议文档。
- [x] 完成 iframe、异步按钮、静态 Pages 与完整转账联动验收，并记录构建和代码复核结果。

## Verification

- 原生算法 5 项检查通过：独立 Node HMAC 对照、金额规范化、篡改与错误密钥拒绝、非法金额，以及同金额 256 次随机生成均不同。
- 网银 11 项浏览器检查通过：随机 DOM、两种登录、取消后换号、二次确认与回执编号相同、同金额连续转账编号不同。
- 登记本地与静态 Pages 版本各 10 项浏览器检查通过，覆盖真实 iframe、独立签名与实际网银编号、金额绑定、错误提示、重置、Enter 和窄屏。
- TypeScript、普通与 Pages 构建、脚本语法及差异空白检查通过。只读代码复核无待修复项，已查看桌面和移动端截图。
- 此无状态前端方案用于模拟，不承诺严格历史去重或密钥保密；限制已写入 `fixtures/README.md`。
