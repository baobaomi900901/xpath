# iframe 登记表单

- 新增独立首页入口“登记”，路由 `/registration-test`，页面标题及浏览器标题为“登记”。
- 外层页面只承载标题与真实 iframe；iframe 标题为“登记表单”，内部路由 `/registration-form-content`。沿用已有页面的 BrowserRouter / GitHub Pages HashRouter 地址规则。
- 所有输入、重置/登记按钮、登记成功及失败弹窗均在 iframe 文档中，不在外层页面复制控件。
- 按截图包含业务流水号、转账账号、金额、客户名称、收款银行、分行支行名称、联行号、转账用途。初始为空，前六项必填，联行号和转账用途选填。字段使用稳定中文标签、唯一 id 及正确 label 关联。
- 业务流水号使用 `fixtures/bank-transfer-auth.json` 中的相同密钥验证 HMAC-SHA256 签名与金额。拒绝空值、旧固定编号、编造/篡改编号、错误金额、大小写变化及额外空格；不再依赖 10 条白名单或编号序列。
- 其他字段复用网银表单的必填、账号及金额校验。点击登记或按 Enter 校验；错误以“登记失败”弹窗反馈并保留输入，成功以“登记成功”弹窗展示登记摘要。
- 重置按钮清空登记信息。不添加持久化记录或网络写入，不要求先登录网银。
- 浏览器验证真实 iframe 边界、8 项标签定位、网银实际生成及独立 Node HMAC 生成的随机编号、篡改/错误密钥/金额/空格拒绝、必填与格式、重置、Enter、窄屏及 Pages 路径。
