# 元素串匹配测试

用户已确认：独立首页入口，固定对照与随机靶元素组合，覆盖 14 种匹配规则。

- 路由 `/element-match-test`，复用 PageLayout 与 Ant Design 卡片。
- 原生按钮作为真实靶元素，展示 id、title、data-value 与文本。点击后在状态区记录样本和当前值。
- 随机样本：`abc` + n 位随机码、n 位随机码 + `xyz`、`abc` + n 位随机码 + `xyz`。n 默认 8，允许 1–32 位，字符集为大小写字母与数字。刷新或点击重新生成时变化；编辑位数时保持现有样本，点击生成后应用。
- 固定字符串样本：`abc-fixed-xyz`、`def-fixed-uvw`、`Abc-fixed-XYZ`，用于正反例和大小写对照。
- 数值样本：2、99、100、101、1000，阈值为 100，按数值比较。
- 规则表覆盖等于、不等于、包含、不包含、开头为、开头不为、结尾为、结尾不为、大于、大于等于、小于、小于等于、正则、通配符。每行显示属性、条件、命中与不命中样本的当前值。
- 字符串示例区分大小写。正则使用完整锚定及随机码长度约束；通配符约定 `*` 为任意长度、`?` 为单个字符，整串匹配，提供两种示例。
- 不实现额外匹配引擎。外部工具实际运行规则，页面提供参考结果；否定规则应限定在相应样本范围内。
- 浏览器验收验证首页入口、真实 DOM、全部规则正反例、数值边界、生成与刷新、位数上下限、点击反馈及窄屏布局。执行 TypeScript 与 Vite 构建。
