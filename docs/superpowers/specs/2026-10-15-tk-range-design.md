# Tk 框架靶场

参考 `WIN32/src/main.cpp` 的标准版，新增 Python tkinter/ttk 桌面靶场。使用 Python 3.8+ 标准库，不下载运行时、不安装 pip 依赖。优先服务 Windows 元素探测、输入、菜单、分页及拖拽测试；保留 Tk 本身的控件与可访问性表现，不添加 Win32 UIA/MSAA Provider。

## 界面与行为

- 主窗口标题为“Tk 靶场 - tkinter/ttk”，初始 1180×860，最小 960×760。三个 Tab 为“表单控件”“表格数据”“拖拽测试”。各页随窗口缩放。
- 表单沿用姓名、密码、邮箱、年龄（18–80，默认 25）、城市单选、城市多选、性别、兴趣多选、多行备注、协议等十个字段。默认北京、男，其他字段为空或未选中。保存弹出“提交成功”模态提示，重置恢复默认值。
- 顶部文件/编辑菜单和表单按钮展开的操作菜单沿用 Win32 的项目与状态反馈。操作菜单每次创建、关闭后销毁；操作只更新测试状态，不访问用户文件。
- 表格使用 ttk.Treeview，保持 1000 条确定性员工数据、七列、每页 20 条、50 页，以及首页/上一页/五个相邻页码/下一页/末页。边界按钮禁用，提供横纵滚动条。
- 拖拽页使用 Tk Frame 中的实际 Button 作为 120×80 的 `drag-target`，避免用 Canvas 模拟其他页面的控件。支持边界约束、居中重置、销毁隐藏与重建恢复、鼠标抓取、九宫格锚点、移动次数和耗时。复制 JSON 字段顺序与 Win32 的 `DragStateJson()` 一致。
- 控件使用稳定 Tk widget path，文档列出主要路径；Tk path 不承诺等同于 Windows AutomationId。实际 UIA/MSAA 树由本机 Python/Tk 决定。

## 结构与启动

`TK/` 是可用 `python -m TK` 运行的包。主窗口、三个页面和不依赖 GUI 的数据/拖拽模型各自独立。统一启动命令为 `python tools/start_tk.py`，从任意工作目录调用绝对脚本路径也能运行。启动器复用当前 Python，支持 `--no-launch` 创建并销毁隐藏窗口检查运行环境，及 `--foreground` 前台运行排错。默认启动前检查 tkinter/Tcl/Tk，捕获启动后立即退出并返回错误。

根 README 增加 Tk 靶场索引、依赖、目录和启动命令，`TK/README.md` 记录功能、定位路径和验证命令。保持现有 Win32 与其他未提交修改。

## 验收

使用 unittest 先验证模型及启动器的失败路径，再实现。实际创建 Tk 窗口验证表单输入/重置/保存、菜单创建销毁、分页边界、拖拽事件、隐藏重建、缩放及剪贴板 JSON。Windows 原生菜单和模态提示的阻塞调用在单元测试中替换。运行统一入口的 `--no-launch` 检查和真实子进程启动检查。按用户后续要求，不使用 OCR；开发完成后提供启动命令，由用户进行人工测试。无需对 Tk 不具备的原生 UIA 能力作额外承诺。
