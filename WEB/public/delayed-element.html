测试要点
  • 节点只创建一次，之后只用 appendChild / remove 反复挂载同一个节点 —— 元素的 element_id 按节点身份绑定， 每次新建节点会让旧引用永远等不到。
  • 「存在性」判定不区分可见性：本页是真的把节点移出 DOM， 而不是 display:none。
  • 可用 ?interval=3000 调整最小切换周期（毫秒，默认 1500，最小 100）。
  • 节点创建次数同时写在 #delayed-created-count 文本与 #delayed-host[data-created-count] 属性上（正常恒为 1）； 另有 window.__delayedTargetCreated / window.__delayedTargetVisible 供 MAIN 世界脚本读取（隔离世界读不到页面自己设的 window 变量）。
